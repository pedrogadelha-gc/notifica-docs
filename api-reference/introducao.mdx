Os endpoints desta referência são gerados a partir da especificação OpenAPI
exportada pelo backend, então acompanham a versão em produção.

## Base URL

Todo endpoint é versionado sob `/v1`:

```bash
https://api.notifica.dev/v1
```

## Autenticação

| Credencial | Header | Usada por |
| --- | --- | --- |
| API key | `x-api-key` | Seu servidor, em todos os endpoints fora de `/v1/me` |
| Token de cliente | `Authorization: Bearer <token>` | O dispositivo do cliente final, nos endpoints `/v1/me` |

O token de cliente é emitido pelo seu servidor, nunca pelo navegador ou app —
veja [Quickstart](/quickstart) para o fluxo completo.
